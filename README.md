# 长文审校批注工作台

面向编辑人员的离线长文审校工具：在正文中选取文字创建批注，正文修改后批注仍能准确对应原文。

## 启动方式

\`\`\`bash
npm install
npm run dev        # 开发模式，默认 http://localhost:4174
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm test           # 运行 vitest 单元/组件测试
npm run test:watch # 监听模式测试
\`\`\`

首次打开自动载入一篇示例文稿，也可点工具栏「载入示例」随时恢复。

## 核心功能

- **创建批注**：批注模式下在正文拖选连续文字，在弹出面板中选择问题分类并填写意见。支持同一片段多条批注与范围交叉；点击高亮在重叠批注间循环选中，点击侧栏条目可定位到正文高亮。
- **正文编辑**：点「编辑正文」进入编辑模式。批注前的增删会使批注整体平移；恰好落在片段边界的插入不会扩入批注；修改/删除批注内部文字会将该批注标记为「需要复核」并保留原引用；片段被完全删除则进入「失联」状态（不产生伪造高亮）。多处相同引用各自锚定原位置，不会互相跳转。
- **重新关联**：侧栏「重新关联」进入选取模式，在正文中重新框选文字即可，原引用始终保留。
- **筛选搜索**：侧栏支持按分类、待处理/已解决/需要复核筛选，并按意见与引用文本搜索；顶部横幅提示待复核数量。
- **撤销/重做**：正文编辑、批注增删改、重新关联均可撤销重做（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 或 Ctrl+Y），撤销后新操作清空重做分支；连续输入自动合并为一步。
- **草稿与导入导出**：编辑自动保存到 localStorage，刷新后恢复；可导出含正文、批注与状态的 JSON，导入时严格校验，损坏文件不会覆盖当前工作。支持粘贴正文与导入 UTF-8 \`.txt\` 文件（按文本差异迁移已有批注）。

## 浏览器限制

- 需使用现代浏览器（Chrome / Edge / Firefox / Safari 近期版本），依赖 \`localStorage\`、\`window.getSelection\`、\`Blob\` 下载等 Web API。
- 本工具为纯前端离线应用，草稿仅保存在当前浏览器的 localStorage 中；清除站点数据会丢失草稿，重要工作请及时「导出 JSON」备份。
- 正文与批注位置按 UTF-16 码元偏移计算，中文、表情符号与换行均可正确处理；原文中的 HTML 标签一律按纯文字展示，不会被解析。
- 导入文本文件按 UTF-8 解码；其他编码（如 GBK）的文件可能出现乱码，请先转码。

## 目录结构

- \`src/lib/model.ts\` — 批注数据模型、编辑差异迁移、导入导出校验
- \`src/lib/history.ts\` — 撤销/重做栈
- \`src/components/DocView.tsx\` — 正文渲染、高亮分段与划词选取
- \`src/components/Sidebar.tsx\` — 批注侧栏（筛选、搜索、编辑）
- \`src/App.tsx\` — 工作台主界面
- \`tests/\` — 模型迁移规则、历史栈、高亮渲染与应用级测试
