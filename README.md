# 长文审校批注工作台

离线、纯前端的长文审校批注工具。基于 TypeScript 5.9.3 + React 19 + Vite 6，无需后端，数据只保存在本机浏览器中。

## 启动方式

```bash
npm ci        # 安装依赖
npm run dev   # 开发服务，访问 http://localhost:4174/
npm test      # 运行 Vitest 测试（19 个用例）
npm run build # 类型检查 + 生产构建到 dist/
```

首次打开会自动加载一篇内置示例文稿（中文、表情、换行、`<标签>` 文字均正常显示）。

## 功能与操作

- **创建批注**：在“阅读 / 批注”模式用鼠标选取连续文字，侧栏顶部选择问题分类、填写意见后添加。同一片段可有多条批注，范围可以相互交叉；点击正文高亮或侧栏“定位”可互相滚动定位。
- **正文编辑**：切换“正文编辑”直接修改正文。批注以字符 ID 锚定而非偏移量或文本搜索：批注之前的增删会让批注随原位置移动；插入恰好落在片段边界不会扩入批注；批注内部文字被修改、删除会自动标为“需要复核”，并保留修改前原引用。正文中出现多处相同引用时不会跳到另一处。
- **复核与失联**：复核中的批注在侧栏单独红色提示，可定位仍存在的部分（中间被改时按多段显示）；片段被完全删除时只显示“失联，无高亮”，不会伪造高亮。可“重新关联”选取新片段，或直接删除批注。
- **筛选与搜索**：侧栏按分类、待处理/已解决状态、仅看待复核筛选，并可搜索意见内容、当前关联文字和原引用。“标记解决/重新打开”只改批注状态，不改正文。
- **撤销/重做**：正文编辑、批注增删改、解决状态与重新关联全部进入同一条历史（工具栏按钮，快捷键 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` / `Ctrl+Y`），恢复时正文与批注位置一致；撤销后产生新操作会清空重做分支。
- **草稿与文件**：每次改动自动保存到浏览器 `localStorage`，刷新后恢复；支持“粘贴正文”、导入 UTF-8 TXT，以及导出/导入包含正文、批注与状态的 JSON。导入损坏或结构不符的 JSON 会报错提示且不覆盖当前工作。

## 浏览器限制

- 离线单机应用：自动保存依赖浏览器 `localStorage`（隐私模式下可能不持久；清理站点数据会删除草稿），更换浏览器或设备请通过导出/导入 JSON 迁移。
- TXT/JSON 通过 `FileReader` 按 UTF-8 解码，请确保 TXT 文件为 UTF-8 编码，否则非 ASCII 字符可能乱码。
- 正文锚点基于 JavaScript UTF-16 码元位置，浏览器原生选择/光标行为一致；由其他编辑器粘贴富文本会被当纯文本处理，原标签（如 `<引文>`）按普通文字展示。
- 撤销历史只保留在当前会话（最多 400 步），刷新后历史清空但当前草稿保留。
- 建议使用最新版 Chrome / Edge / Firefox / Safari；窄屏下侧栏会移至正文下方。
